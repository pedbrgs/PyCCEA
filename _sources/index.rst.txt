Documentation
====================

PyCCEA is an open-source Python package for feature selection in high-dimensional datasets using
cooperative co-evolutionary algorithms (CCEAs). It provides a modular framework that enables
researchers and practitioners to implement, evaluate, and extend CCEAs through interchangeable
components such as decomposition strategies, cooperation schemes, fitness evaluation methods, and
evolutionary optimizers.
